# PlantCare – Sistema Experto para el Cuidado de Plantas

Descripción del proyecto

PlantCare es un sistema experto desarrollado en SWI-Prolog, cuyo objetivo es ayudar a identificar posibles problemas en las plantas a partir de sus síntomas y condiciones de cuidado.

El sistema utiliza una base de conocimientos y un conjunto de reglas lógicas para analizar la información proporcionada por el usuario y generar recomendaciones sobre el cuidado de las plantas.


Tecnologías utilizadas
- SWI-Prolog: lenguaje de programación lógica utilizado para desarrollar el sistema experto.

Base de conocimientos: contiene las reglas y recomendaciones para identificar posibles problemas.

Manejo de archivos: almacenamiento de los registros e historial de consultas.
