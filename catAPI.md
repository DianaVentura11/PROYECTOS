# Práctica CatAPI 
– Consumo de servicios web Desarrollo de una aplicación web que integra TheCatAPI, un servicio externo que proporciona imágenes de gatos mediante una API REST. La aplicación realiza solicitudes HTTP utilizando Fetch API y procesa las respuestas en formato JSON para mostrar imágenes dinámicamente en una interfaz web.

Tecnologías utilizadas:

- HTML5
- CSS3
- JavaScript
- Fetch API
- TheCatAPI
- JSON
