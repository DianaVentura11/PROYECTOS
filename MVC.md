Sistema de Agenda de Actividades

Aplicación web desarrollada con Node.js, Express.js y MongoDB, utilizando el patrón de arquitectura MVC (Modelo-Vista-Controlador), que permite a los usuarios administrar sus actividades de manera organizada.

Descripción del proyecto:

El sistema permite registrar usuarios, iniciar sesión y gestionar actividades personales. Además, cuenta con herramientas para consultar el historial de acciones realizadas y generar reportes en formato PDF.

Tecnologías utilizadas

- Node.js: entorno de ejecución de JavaScript.
- Express.js: framework para el desarrollo del servidor.
- MongoDB: base de datos NoSQL.
- Mongoose: modelado de datos.
- Handlebars: generación de vistas dinámicas.
- Bootstrap / CSS: diseño de la interfaz.
- PDFKit: generación de documentos PDF.
- Nodemailer: envío de correos electrónicos.
- Express-session: manejo de sesiones.
- Bcryptjs: protección de contraseñas
